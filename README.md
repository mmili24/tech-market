# 🛒 TechMarket
Sistema de gestió de vendes de productes tecnològics amb Python.
Projecte per aprendre POO, Herència i Polimorfisme.

## 🚀 Com executar-ho
1. Clona el projecte.
2. Executa `python carret_compra.py`

## 🗂️ Estructura del projecte
```
TechMarket/
├── producte.py           # Classe base Producte
├── portatil.py           # Classe Portatil (hereda de Producte)
├── smartphone.py         # Classe Smartphone (hereda de Producte)
├── carret_compra.py      # Classe CarretCompra per gestionar compres
└── test_carret_compra.py # Tests unitaris

## ️ Tecnologies
- Python 3.10
- Unittest
- Git & GitHub
